# Security Policy

## Supported versions

Security fixes are released for the latest minor version of `@aios-inc/cashier`.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a vulnerability

Please do not report security issues in public GitHub issues, pull requests or discussions.

Report them privately through GitHub Security Advisories:

1. Go to [github.com/aios-inc/cashier/security/advisories/new](https://github.com/aios-inc/cashier/security/advisories/new).
2. Describe the issue, the affected versions and the steps to reproduce it.
3. Include a proof of concept if you have one.

We will acknowledge your report within 3 business days, keep you updated while we work on a fix, and credit you in the advisory unless you ask us not to.

Never include real API keys, customer data or payment details in a report. Use Stripe test mode keys or a Recurly sandbox site when you reproduce an issue.
